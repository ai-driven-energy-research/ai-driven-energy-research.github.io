Step 1: Upload manuscript

Upload your main document as a Word (.docx) or PDF file. LaTeX users may upload the PDF, or a .zip archive containing the source and PDF. The title, abstract, authors and keywords are read from the file to pre-fill the following steps; pre-filled fields are highlighted, and you can edit them.

Main document *

Drag and drop the file here, or

Accepted: .docx, .pdf, .zip, .tex · maximum 20 MB
Supplementary files (optional)
For example supplementary information, code or data archives (.zip), or videos. Large datasets should be linked from a repository in Step 6 instead. Total upload limit 25 MB.
